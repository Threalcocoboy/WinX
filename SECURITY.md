# Security policy

Security fixes target the latest stable WinX release. Include the affected version and the circumstances needed to reproduce the issue.

Use [GitHub Private Vulnerability Reporting](https://github.com/Threalcocoboy/WinX/security/advisories/new) when available. If the private form is unavailable, use a GitHub issue to request a private reporting channel and keep technical details out of the issue. Remove credentials, device identifiers, and personal data from attachments before submitting them.

GitHub Releases is the distribution source for WinX. The [update guide](docs/UPDATING.md) explains the installer integrity checks and current signing status.
