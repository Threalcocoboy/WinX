# WinX v1.5.1

WinX red is now the default accent. Open **Settings → Appearance** to choose a custom accent or select **Reset accent** to restore the default. WinX applies your choice immediately to the tray panel, Settings, and notification accents, and remembers it after restart.

Download the Windows x64 installer or portable ZIP and compare it with `SHA256SUMS.txt`. The installer is unsigned. Both builds require the Microsoft Edge WebView2 Runtime.
