# WinX v1.5.0

WinX brings Nothing and CMF device controls to the Windows notification area. This first public WinX release brings together the Windows tray app, separate Settings window, guided onboarding, and release updates. Developed and maintained by **Threalcocoboy**.

## What's included

- Battery readings, ANC and Transparency, supported EQ, bass enhancement, low latency, and model-specific controls.
- Configurable Windows hotkeys, connection popups, battery alerts, and supported in-ear and hardware-media overlays.
- Talk Mode on **Ctrl + Alt + H**, with capability-aware speech EQ, a fade to 5% by default, Transparency, and saved recovery for the original device and audio output.
- **Settings → Updates** for automatic or manual GitHub release checks, preview opt-in, release notes, and integrity-checked downloads. WinX asks before opening the unsigned installer and waits for Talk Mode recovery before closing.

## Install on Windows 10 or 11 x64

Download **WinX-v1.5.0-Setup-x64.exe** and compare its SHA-256 with **SHA256SUMS.txt**. Open Setup, launch WinX from Start, and follow onboarding to pair a device. Setup uses Microsoft's Evergreen WebView2 bootstrapper if WebView2 is absent. To use the portable build, extract the entire ZIP and run **nothingx-desktop.exe** with WebView2 installed. The source ZIP contains the corresponding application and packaging source.

## Compatibility and verification

The earlier WinX Windows build has a user report for Nothing Ear (3). Upstream reports hardware tests for CMF Buds 2 Plus and CMF Buds Pro 2 on macOS. Other model profiles are experimental on Windows. Bluetooth controls, Talk Mode, and device-specific overlays depend on feature support and firmware.

The release workflow gates publication on Windows x64 compilation, Rust and UI checks, a portable-app startup/exit smoke test, package verification, and matching uploaded digests. Live device tests and a full interactive installer-upgrade test remain pending for this release.
